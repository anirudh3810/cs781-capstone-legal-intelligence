# Repository completeness review

The seven selected implementations, four original Phase 1 architectures, phase notebooks, evidence and requirements were checked against the local final-submission package. The final report PDF, LaTeX source, figure scripts and supporting project source/notebook variants have been added. Existing curated phase implementations are preserved. `source_archive/` contains additional local source snapshots, with notebook outputs cleared for public distribution. `reference/course_slides/` contains the available course reference PDFs.

The final report-and-code submission ZIP and small submission/report archives are attached to the [coursework release](https://github.com/anirudh3810/cs781-capstone-legal-intelligence/releases/tag/coursework-2026-11-19). The ZIP is the original submitted snapshot; the current Git repository also contains the subsequent publication additions.

The official capstone corpus is restricted and remains outside this public repository. Several multi-gigabyte all-artifact/recovery ZIPs contain official input data or model weights; those remain local/private Kaggle Inputs, as described in the original README. Local virtual environments, installed rendering tools, temporary render output, resumes and application shortcuts are not project source and were excluded.

See `evidence/publication_inventory.json` for source paths and checksums. This check verifies the saved publication structure and source syntax, not a fresh training run or current leaderboard scores.
