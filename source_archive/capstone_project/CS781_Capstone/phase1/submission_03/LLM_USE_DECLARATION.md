# LLM Use Declaration - Submission 03 Infrastructure

AI assistance was used to review the published capstone requirements and to
prepare ancillary infrastructure for data validation, checkpointing, recovery,
runtime tests, prediction management, and submission packaging.

The generated infrastructure proposes a high-level integration contract for a
single-stack prefix-hybrid language model so that it can be compared with the
decoder-only and encoder-decoder submissions.

AI assistance was not used in this artifact to provide the submitted model's
complete implementation, choose its numerical architecture, tune training
hyperparameters, fabricate experimental results, or write scientific
conclusions. Those items remain explicit student-owned requirements and are
blocked by notebook attestations until supplied.

The student must update the final course declaration to describe their actual
use before submission.
